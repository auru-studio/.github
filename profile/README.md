# Auru Studio

We're making a Collaborative DAW & open sourcing key components / tools, you can learn more about the DAW at [auru.studio](https://auru.studio)

## [Auru PM](https://github.com/auru-studio/auru-pm-core)

Git-like history and sync for DAW projects. Auru PM can snapshot, compare, merge, and restore projects from Ableton, Bitwig, Fruity Loops & `.dawproject` projects. Revisions live in a content-addressed store and can be shared through pluggable sync providers.

## [GPUI Audio Components](https://github.com/auru-studio/gpui-audio-components)

Reusable Rust components for building audio applications with GPUI. The library includes waveforms, meters, automation curves, timeline controls, faders, knobs, and interaction helpers, plus a UI-independent crate for multi-resolution waveform data.
